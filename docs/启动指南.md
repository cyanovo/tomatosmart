# 快速启动指南

本指南帮助你在 5 分钟内启动番茄温室智能管控平台。

## 前置条件

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (Windows/Mac) 或 Docker Engine (Linux)
- 至少 8GB 可用内存
- [硅基流动 API Key](https://cloud.siliconflow.cn/i/Eo5yTHGJ)（免费注册）

## 第一步：克隆项目

```bash
git clone <repository-url>
cd Newsmart-Strawberry
```

## 第二步：配置环境变量

### 方式一：使用初始化脚本（推荐）

**Windows PowerShell:**
```powershell
.\scripts\init.ps1
```

**Linux / macOS:**
```bash
chmod +x scripts/init.sh
./scripts/init.sh
```

脚本会引导你填写必要的配置，并自动生成 `.env` 文件。

### 方式二：手动配置

```bash
# 复制模板
cp .env.template .env

# 编辑 .env 文件，填写以下内容：
# - SILICONFLOW_API_KEY（必填）
# - 其他配置项可保持默认
```

## 第三步：启动服务

```bash
# 构建并启动所有服务
docker compose up -d --build

# 查看启动日志
docker compose logs -f api-dev
```

等待看到 `Application startup complete` 表示服务已就绪。

## 第四步：访问系统

打开浏览器访问：**http://localhost:5173**

首次访问时，系统会引导你创建管理员账户。

## 第五步：验证功能

### 基本功能

1. **登录系统** - 使用刚创建的管理员账户
2. **查看仪表盘** - 检查环境数据展示
3. **AI 对话** - 点击右下角悬浮球，与 AI 助手对话

### IoT 功能（可选）

如果需要使用物联网功能：

1. 确保 MQTT 已启用（`.env` 中 `MQTT_ENABLED=true`）
2. 查看 MQTT 日志：`docker logs mosquitto -f`

### 摄像头检测（可选）

如果需要使用番茄成熟度检测：

```bash
# 安装依赖
pip install ultralytics opencv-python fastapi uvicorn pydantic

# 启动本地检测服务
python scripts/run_detect_local.py
```

> **注意**：Docker 容器无法直接访问电脑摄像头，检测服务需要在本地运行。

## 日常使用

### 启动系统

```bash
# 启动所有服务
docker compose up -d

# 启动本地检测服务（新终端，可选）
python scripts/run_detect_local.py
```

### 停止系统

```bash
# 停止所有服务
docker compose down

# 停止本地检测服务：Ctrl+C
```

### 重启系统

```bash
# 重启所有服务
docker compose restart

# 重启单个服务
docker compose restart api-dev    # 重启后端
docker compose restart web-dev    # 重启前端
docker compose restart postgres   # 重启数据库
```

### 查看日志

```bash
# 查看所有服务日志
docker compose logs -f

# 查看单个服务日志
docker logs api-dev -f            # 后端日志
docker logs web-dev -f            # 前端日志
docker logs mosquitto -f          # MQTT 日志
docker logs postgres -f           # 数据库日志
```

### 检查状态

```bash
# 查看服务状态
docker compose ps

# 检查环境配置
.\scripts\check-env.ps1          # Windows
./scripts/check-env.sh           # Linux/Mac
```

### 更新代码后

```bash
# 拉取最新代码
git pull

# 重新构建并启动
docker compose up -d --build
```

### 清理数据（谨慎使用）

```bash
# 停止并删除所有容器和数据卷
docker compose down -v

# 重新启动（会重新初始化数据库）
docker compose up -d --build
```

## 常见问题

### 1. 服务启动失败

```bash
# 检查环境配置
.\scripts\check-env.ps1  # Windows
./scripts/check-env.sh   # Linux/Mac

# 查看详细日志
docker compose logs api-dev
```

### 2. 端口被占用

```bash
# 检查端口占用
netstat -ano | findstr :5173  # Windows
lsof -i :5173                 # Linux/Mac

# 修改 docker-compose.yml 中的端口映射
```

### 3. 数据库连接失败

```bash
# 重启数据库服务
docker compose restart postgres

# 检查数据库日志
docker logs postgres
```

### 4. MQTT 连接失败

```bash
# 检查 Mosquitto 状态
docker logs mosquitto

# 确保防火墙允许 1883 端口
```
